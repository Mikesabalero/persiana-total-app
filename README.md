# Persiana Total - Sistema de Presupuestos

Aplicación web para gestión de presupuestos de persianas, cortinas y automatizaciones.

## Estructura
- `index.html` - Estructura HTML
- `styles.css` - Estilos CSS
- `app.js` - Lógica JavaScript
- `logo.svg` - Logo de la empresa

## Backend
- NocoDB como base de datos (API REST)
- Nginx como servidor web

## Stack
- HTML/CSS/JS vanilla
- NocoDB API v2
- Docker + Nginx
